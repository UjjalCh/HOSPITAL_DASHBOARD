# Hospitals Insights Dashboard

## 📊 Dashboard Overview

The Hospitals Insights Dashboard provides an interactive overview of hospital performance, patient information, medical expenses, doctors, departments, locations, and hospital admissions. It brings important healthcare data together in one place for easy analysis and comparison.

## 🏥 Hospitals Name Filter

The Hospitals Name filter allows users to select a specific hospital and analyze its patient, doctor, department, admission, and expense information.

## 📍 Location Filter

The Location filter allows users to analyze hospital data based on different cities and locations such as Ahmedabad, Bangalore, Chennai, Delhi, Hyderabad, Jaipur, and other available locations.

## 🩺 Department Filter

The Department filter allows users to select a specific medical department, such as Cardiology, Dermatology, ENT, Neurology, Urology, Gynaecology, and others.

## 👥 Total Patients

The Total Patients KPI displays the overall number of patients included in the selected hospital and filter criteria.

## 💰 Total Expense

The Total Expense KPI shows the total medical expenses recorded across the selected hospitals, patients, departments, and locations.

## 👨‍⚕️ Total Doctors

The Total Doctors KPI displays the total number of doctors associated with the selected hospital data.

## 👥 Total Patients by Hospital Name

The Total Patients by Hospital Name chart shows the distribution of patients across different hospitals. It helps users compare patient volumes between hospitals.

## 💰 Total Expense by Location

The Total Expense by Location visualization shows medical expenses across different locations. It helps identify locations with higher or lower healthcare expenses.

## 📋 Hospital Patient Details Table

The Hospital Patient Details table provides detailed information about hospitals, admission dates, discharge dates, locations, departments, total patients, and total expenses.

## 🩺 Patients by Department

The Patients by Department visualization shows the number of patients across different medical departments. It helps users understand which departments handle higher patient volumes.

## 💵 Medical Expenses by Department

The Medical Expenses by Department chart compares medical expenses across different departments. It helps identify departments with higher healthcare expenditure.

## 👨‍⚕️ Number of Doctors by Hospital

The Number of Doctors by Hospital chart displays the number of doctors available at different hospitals. It allows users to compare doctor availability across hospitals.

## 🏥 Hospital Performance Analysis

The dashboard allows users to compare hospitals based on patient volume, number of doctors, medical expenses, departments, and other available healthcare information.

## 📅 Admission and Discharge Analysis

The patient details section includes admission and discharge dates, allowing users to examine patient activity and understand hospital admission and discharge patterns.

## 🌍 Location-Based Healthcare Analysis

The dashboard provides a location-based view of patients, hospitals, doctors, and medical expenses. This helps users understand how healthcare activity varies across different cities.

## 🔎 Interactive Analysis

The Hospitals Insights Dashboard is interactive. When users select a hospital, location, or department, the KPIs, charts, tables, and other visualizations update according to the selected filters.

## 💡 Key Insights

The dashboard helps users understand patient distribution, hospital activity, medical expenses, doctor availability, department-wise patient volume, and location-wise healthcare performance.

## 📌 Data-Driven Healthcare Analysis

The Hospitals Insights Dashboard combines hospital, patient, doctor, department, expense, admission, and location data into a single interactive report. It provides a clear visual representation of healthcare information and helps users analyze important patterns and trends.

## 📊 Healthcare Performance Monitoring

The dashboard can be used to monitor patient volumes, medical expenses, doctor availability, department performance, and hospital activity through interactive charts and KPIs.
